# *What to Eat Today _Web* 今天吃什么 网页版

基于[What2EatToday桌面版](https://github.com/Bachop/What2EatToday)迁移，支持账号、游客及群组共享抽签、反悔次数和午餐日历。运行 `.\.venv\Scripts\python.exe .\server.py` 后访问 `http://127.0.0.1:8000`。

## 快速启动

需要 Python 3.11 或更新版本。本地试用无需安装新的运行依赖。在工作区根目录运行：

```powershell
.\.venv\Scripts\python.exe .\server.py
```

浏览器打开 **http://127.0.0.1:8000**。也可以双击 `run.bat`。网页需通过服务访问，不能通过双击 `index.html` 使用账号与共享功能。

首次访问提示登录或注册，也可以选择游客。注册后直接登录。勾选“记住账号密码”后 30 天内保持登录；不勾选时使用浏览器会话凭证，服务端最多保留 12 小时。退出登录立即撤销当前凭证。密码允许任意种类字符，包括空格、中文、表情，长度为 4～16 个 Unicode 字符。用户名忽略大小写去重。

## 多人使用

在同一局域网内，服务所在电脑运行：

```powershell
.\.venv\Scripts\python.exe .\server.py --host 0.0.0.0 --port 8000
```

其他人使用浏览器访问 `http://服务电脑的局域网IP:8000`。Windows 防火墙需放行实际使用的端口。**所有人必须访问同一个服务及其数据库**；每个人各自启动一个服务不会共享账号和群组。

1. 每人注册独立账号。游客可使用完整的个人抽签、清单、权重和日历功能；加入群组需要账号。
2. 创建者填写群名及唯一群组号（8～16 位数字、大小写英文字母）。创建群组时会复制个人午餐清单及权重；个人历史不会共享。
3. 其他人搜索群组号并点击加入。每个账号同时只能有一个群组，所有成员均可管理群清单。
4. 群成员共用每天的抽签结果和 3 次反悔额度。首次抽签免费；第一次反悔直接执行，第二、三次需要确认。取消不扣次数。页面约 2 秒自动同步，恢复页面可见时也会刷新。
5. 日历仅共享入群日期起的群记录，并标注群名。退群当日保存已有记录快照，之后不再更新；个人记录保留且不标注群名。同一天不同来源的记录可分别查看。
6. 创建者退出时移交给最早加入的成员，最后一人退出后群组归档，群组号不再复用。退群再加入不会补齐中间离开期间的历史。

日期统一按服务端 UTC+8；防重复、轮换及权重算法与桌面版相同，不按各客户端的日期执行。连接失败会保留上次显示的数据并提示，服务恢复后继续同步。

## 数据与备份

默认数据库为 `data/web.sqlite3`，启动时自动创建并在终端显示绝对路径。账号、密码哈希、群组、个人及群组日历均存在这个数据库；浏览器只保存登录凭证。游客数据依赖当前浏览器的凭证，清除 cookie、凭证过期或切换账号后不能将其视作账号数据恢复；注册和登录不会自动合并游客数据。

可指定独立数据目录：

```powershell
.\.venv\Scripts\python.exe .\server.py --data-dir D:\LunchWebData
```

备份时停止服务，复制整个数据目录，再启动服务。不要只在运行中复制 `.sqlite3` 主文件而遗漏 WAL。新版本不会读取或修改桌面版 `lunch.db`。数据库和运行产物已从 Git 排除。

## 长期运行或部署到服务器

局域网试用可使用默认开发服务器。长期运行可安装 Waitress（与 PySide6 无关）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
.\.venv\Scripts\python.exe .\server.py --production --host 0.0.0.0 --port 8000
```

也可单独复制项目目录，用服务器自己的 Python 环境安装 `requirements.txt` 后运行 `python server.py --production`。无需复制原桌面包。

互联网部署需要可访问的服务器或云主机、持久磁盘及 HTTPS。让反向代理转发到本机服务并保留浏览器原始 Host；服务绑定 `127.0.0.1`，添加 `--secure-cookie`，由代理终止 HTTPS。不要在普通 HTTP 访问时启用该选项，否则浏览器不会发送 Secure cookie。当前限流按服务看到的客户端地址执行，不盲信任客户端转发头；反向代理后多个用户会共用代理地址的限流额度（每地址 10 分钟最多 60 次登录/注册尝试）。

此实现面向一个服务实例的小规模多人使用，SQLite 数据库应放在服务本机持久磁盘。无需预先开通云数据库。多实例、高并发或无持久磁盘的托管环境需要另行切换数据库，不适合直接复制当前 SQLite 文件到每个实例。

## 目录

```text
W2ET_Web/
  server.py                 启动入口：本地预览 / Waitress
  run.bat                   Windows 启动脚本
  requirements.txt          长期运行的可选依赖
  lunch_web/
    app.py                  账号、群组及午餐 API
    database.py             多用户 SQLite 结构
    security.py             密码哈希与会话
    core/                   独立复制的算法及作用域存储适配
  static/                   HTML / CSS / JavaScript
  tools/                    可选浏览器验证
  data/                     自动创建，已忽略
```
